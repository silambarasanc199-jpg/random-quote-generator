# ✦ QuoteFlow – Random Quote Generator

A professional and responsive Random Quote Generator built using HTML5, CSS3, and JavaScript as part of the Veda Technology Web Development Internship – Day 8 task.

## 📌 Project Overview

QuoteFlow is a client-side web application that displays inspirational quotes and their authors. Users can generate a new random quote, copy it to the clipboard, or share it using the browser's native sharing functionality.

The project focuses on practicing JavaScript arrays, random number generation, DOM manipulation, event handling, browser APIs, and responsive web design.

## 🎯 Objective

To develop an interactive Random Quote Generator that:

- Stores at least 10 quotes in JavaScript.
- Generates quotes randomly.
- Displays the corresponding author.
- Prevents the same quote from appearing consecutively.
- Provides copy and share functionality.
- Works smoothly on desktop and mobile devices.

## ✨ Features

- 🎲 Random quote generation
- 👤 Author display
- 🚫 Consecutive duplicate prevention
- 📋 Copy quote to clipboard
- 📤 Share quote functionality
- 📱 Fully responsive design
